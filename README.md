## 📖 使用方式

### Obsidian（推荐）
1. 克隆仓库到 Obsidian Vault 目录
2. 安装插件 **Math+** 或开启内置 LaTeX 支持
3. 打开 `.md` 文件即可渲染公式和图片

### Typora
直接打开 `.md` 文件，公式自动渲染。

### VS Code
安装插件 **Markdown Preview Enhanced**，支持 KaTeX 数学公式。

## 🤝 如何贡献

**最需要的贡献：提供 PDF 原始试卷！**

有扫描清晰的真题 PDF？按以下任意方式提交即可，Markdown 转化由维护者负责完成 🙏

### 方式一：提 Issue（最简单）

1. 点击仓库顶部 [Issues](../../issues) → **New Issue**
2. 标题格式：`[PDF] 年份 + 考试类型 + 卷型 + 学科`
   - 示例：`[PDF] 2025高考 全国二卷 数学`
3. 正文附上 PDF 文件（可直接拖拽上传）或网盘链接

### 方式二：直接 PR

1. Fork 本仓库
2. 将 PDF 放入对应目录：`{考试类型}/{年份}/{卷型}/{学科}/`
3. 同时提交 MD 文件（如已整理）或仅提交 PDF 亦可
4. 发起 Pull Request，说明试卷来源

### 收录优先级

| 优先级 | 类型 |
|--------|------|
| 🔴 高 | 高考全国卷（数学、语文、英语、物理、化学、生物） |
| 🟡 中 | 高考地方卷（北京、上海、广东等） |
| 🟢 普通 | 中考、模拟卷、联考卷 |

> **质量要求**：PDF 扫描清晰（可识别文字为佳），注明年份和卷型即可。
